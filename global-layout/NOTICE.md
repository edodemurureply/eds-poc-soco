# Provenance

Portable copy of the custom layout and four supported blocks from `eds-demo-site`,
initially extracted October 9, 2026, now using the Global Layout contract
(`global-layout`, `global-layout-columns`). This is a separately maintained copy,
not an automatically synced export; the site has its own implementation.

The image helper and rich-text helper originate in the Adobe AEM boilerplate
(Copyright 2020 Adobe, Apache-2.0). See `LICENSE`.

`vendor/dompurify.min.js` preserves the site's existing DOMPurify 3.2.4 dependency
and license header (Cure53, Apache-2.0 OR MPL-2.0). Review/update this pinned
dependency under the target project's security process before production use.
This extraction does not constitute a dependency security audit.
